# Task Management Application

A full-stack Task Management Application developed using Java and Spring Boot. The application allows users to register, log in, and manage their tasks securely.

## Features

- User registration and login
- Secure authentication and session handling
- Add new tasks
- View tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- REST API integration
- PostgreSQL database
- Responsive web interface
- Deployed frontend and backend

## Technologies Used

### Backend
- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL

### Frontend
- HTML
- CSS
- JavaScript

### Deployment & Tools
- GitHub
- Render
- Railway
